# FPV 穿越机 30 天入门教程

从零开始，30 天系统学会穿越机（FPV）飞行。

## 目录结构

- `index.html` — 单文件版电子书，浏览器直接打开即可阅读，自带侧边目录导航；已内置 A4 打印版式，浏览器内直接「打印」即可成册
- `FPV穿越机30天入门教程-打印版.pdf` — A4 打印稿，可直接送印

## 在线阅读

仓库开启 GitHub Pages 后访问：

```
https://make1477.github.io/fpv-book/
```

## 本地阅读

直接用浏览器打开 `index.html` 即可，无需任何环境。

## 内容

- 14 个章节，从认识设备到独立飞行
- 83 个小节，含 betaflight 配置、图传设置、飞行技巧等实操内容
- 9 个实飞训练科目（含新增「刷锅」左右分练）
- 8 个附录：术语表、飞前检查单、常用参数速查、器材采购、法规链接、安全红线、2025 世界大赛赛道解析、版本说明
- 引用了 [Betaflight 官方文档](https://betaflight.com/)、[mdBook](https://github.com/rust-lang/mdBook) 与民航局无人机管理相关[无人机驾驶员管理规则](https://www.gov.cn/zhengce/content/202306/content_6888799.htm)

## 说明

本书内容仅供学习参考，飞行前请遵守当地法律法规，务必在合法合规的空旷场地练习。
法规条款与赛事规则会更新，飞行与备赛前请以官方渠道当日公布的版本为准。
